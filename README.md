# Maheen Arshad - Portfolio

Personal portfolio built with HTML5, CSS3 and vanilla JavaScript. No frameworks.

## Files

```
portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── profile.jpg              (your photo)
    ├── Maheen-Arshad-CV.pdf     (your CV)
    └── design/                  (your design images)
```

## Things to edit (search for "TODO" in index.html)

1. Profile photo: replace the `photo-placeholder` div in the hero.
2. CV: save it as `assets/Maheen-Arshad-CV.pdf`.
3. GitHub username: replace `YOUR-USERNAME` (contact section + footer).
4. Project GitHub links: replace each `href="#"`.
5. Placeholder projects and the design gallery: swap in your real work.
6. Colours: edit the variables at the top of `style.css`.

## Run locally

Open the folder in VS Code, install the **Live Server** extension, right-click `index.html` and choose **Open with Live Server**.
